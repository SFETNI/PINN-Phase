# Phase-local transfer across domain size and grain number

One phase-local model, a shared bias-free rule of 2,160 learned
parameters applied to each phase field separately, followed by a margin repair and
a Euclidean projection onto the simplex. It was trained once at 48^3 with eight
grains on four initial microstructures and is applied unchanged, at fixed grid
spacing, to three unseen microstructures in each of four regimes. The regimes are
reported separately and never pooled; microstructure numbers are local to each
regime. Time is t = 0.01 s for step s.

The weights are distributed as `checkpoints/phase_local_48_n8.weights.npz`; the accepted training
checkpoint (`764f22a548e4...`) is not. `expected_score.json`
is built from the accepted evaluation records by
`scripts/package_phaselocal_transfer.py`, which binds each record by SHA-256.

## Training

4 initial microstructures at 48^3 with 8 grains,
28,200 optimizer updates in 1,410 cycles, one-step targets of the
reference map evaluated on the model's own generated states. Four autonomous trajectories, one per initial microstructure, advance ten learned steps each without keeping their computational graphs, followed by twenty Adam updates; each trajectory restarts from its initial field after 3,000 steps. A first-in first-out buffer of capacity 240 starts with the four initial fields and receives each trajectory's state every ten steps, so it holds only initial fields and states generated by the model itself. Every update draws six crops (20^3 interior, 3-cell halo) from uniformly chosen buffer states at uniform periodic offsets. The target is one application of the reference map to the sampled state, computed without gradient and restricted to the interior; the loss is the mean over crops and interior voxels of the squared difference summed over phases, without time-step scaling. Adam, cosine learning rate from 1e-3 to 1e-4, 28,200 updates in 1,410 cycles. Convolution weights are initialized uniformly on +/-(27 c_in)^(-1/2), the third convolution multiplied by 0.1. No training
command is distributed; the recipe above is the disclosure. The four training
initial label arrays in `initial_labels/` are regenerated from the recorded generation parameters of the periodic Voronoi construction; the training program rebuilt these fields at the start of the run and did not save them, so no stored copy exists to compare with.

## Acceptance criteria

- (i) structural consistency: permuting the phase fields commutes with one step to within 1e-15, appended zero phases stay exactly zero and leave the existing phases bitwise unchanged, and every output is finite, nonnegative and sums to one within 1e-12; assessed once per regime on fields that are not scored cases
- (ii) admissibility: every prescribed step is completed and every state is finite, nonnegative and has maximum unit-sum error at most 1e-12
- (iii) alive/extinct sets and extinction timing: the alive set equals the reference alive set at every evaluation time, the extinct set equals the reference set, every extinction step lies within max(100, 0.1 s_ref) steps of the reference step, and no extinct phase returns
- (iv) field error relative to persistence: E_TV(model) / E_TV(persistence) is at most a(s) at every evaluation time with t >= 5, with a = 0.5 and a = 0.25 at the final step
- (v) grain-volume error: the maximum normalized grain-volume error is at most 0.05 at every evaluation time

Criterion (i) is assessed once per regime; criteria (ii) to (v) per case. A
grain is alive while its diffuse volume exceeds 1e-6; extinction steps come from
the diffuse volumes, never from label images.

## Initial microstructures

`initial_labels/<regime>_microstructure_<k>.npz` holds the initial grain labels of
every scored case (`labels`, uint8, shape (n, n, n), and `n_grains`). The initial
field is the one-hot field of these labels, which is also its own simplex
projection; for every case its grain volumes equal the recorded step-0 volumes, and
where reference labels were stored they equal the labels at step 0. Admission
selected extinction-bearing microstructures, so the cases do not estimate
performance on unselected ones.

## Release assets

Per-step grain volumes and argmax label arrays are attached to the GitHub release
v3.0.0 of this repository, one zip per regime, listed with SHA-256 and size in
`manifest.json`. Unpacked, they form `phaselocal_transfer/<regime>/microstructure_<k>/`
beneath an asset root.

## Verify

```bash
python scripts/verify_phaselocal_transfer.py --records benchmarks/phaselocal_transfer/expected_score.json
```

With the release assets unpacked beneath an asset root, the verifier also checks
every asset against the manifest and recomputes alive sets, extinction steps,
grain-volume errors, label disagreement and the 150-grain statistics from them:

```bash
python scripts/verify_phaselocal_transfer.py --records benchmarks/phaselocal_transfer/expected_score.json --asset-root /path/to/asset-root
```
